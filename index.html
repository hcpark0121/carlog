한마디 차계부

말 한마디로 주유 기록 · 광고·로그인 없음

자주 묻는 것

시리로 기록하려면?
«시리야, 한마디 차계부에 기록»이라고 말한 뒤 «가득 5만 원 43리터»처럼 말하세요. «세차 만 원», «엔진오일 교환 8만 9천 원»도 알아서 나눠 적어요.
잠금화면에 버튼을 두려면?
잠금화면을 길게 눌러 사용자화 → 아래 버튼을 빼고 ＋ → «한마디 차계부 — 주유 기록».
폰을 바꿀 때는?
설정 → 백업 파일 만들기로 파일을 만들어 두고, 새 폰에서 설정 → 백업 파일에서 되살리기.
자동차세·검사 날짜가 맞나요?
최초등록일·배기량으로 계산한 예상값이에요(지방세법, 2025년 개정 정기검사 규칙 기준). 실제 날짜는 고지서·자동차365로 확인해 주세요.
